As encomendas online ainda não estão ativas

As encomendas ficam guardadas numa base de dados gratuita Cloudflare D1 que só o proprietário pode ler. Para a ativar:

  1. Em worker/, inicie sessão com npx wrangler login e crie a base de dados: npx wrangler d1 create ofst-orders. Cole o database_id em worker/wrangler.jsonc.
  2. Crie as tabelas: npm run db:remote (dentro de worker/).
  3. Defina o seu acesso de administrador: npx wrangler secret put ADMIN_EMAIL e npx wrangler secret put ADMIN_PASSWORD (12+ caracteres).
  4. Coloque o endereço do seu site em ALLOWED_ORIGINS em worker/wrangler.jsonc e publique a API com npm run deploy.
  5. Copie o endereço do Worker que aparece (https://ofst-api….workers.dev) para src/data/site.json como apiUrl. Nunca coloque uma palavra-passe nesse ficheiro.
  6. Execute npm run build e depois faça commit e push.

O guia completo está em guides/CLOUDFLARE-SETUP.md. A ferramenta de ficheiros de impressão abaixo funciona sem base de dados.

Orders are stored in a free Cloudflare D1 database that only you can read. To switch it on:

  1. In worker/, log in with npx wrangler login and create the database: npx wrangler d1 create ofst-orders. Paste the database_id into worker/wrangler.jsonc.
  2. Create the tables: npm run db:remote (inside worker/).
  3. Set your admin sign-in: npx wrangler secret put ADMIN_EMAIL and npx wrangler secret put ADMIN_PASSWORD (12+ characters).
  4. Put your website address in ALLOWED_ORIGINS in worker/wrangler.jsonc, then publish the API with npm run deploy.
  5. Copy the Worker address it prints (https://ofst-api….workers.dev) into src/data/site.json as apiUrl. Never put a password in that file.
  6. Run npm run build, then commit and push.

The full walkthrough is in guides/CLOUDFLARE-SETUP.md. The print-file tool below works without a database.

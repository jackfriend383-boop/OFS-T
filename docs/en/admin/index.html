Orders are stored in a free Supabase database that only you can read. To switch it on:

  1. Create a Supabase project (region: EU, e.g. Frankfurt).
  2. Open SQL Editor, paste the contents of supabase/schema.sql from the repository and click Run.
  3. In Authentication, turn off public sign-ups, then add yourself as a user (Users → Add user).
  4. Copy your user's UID and run insert into public.admins (user_id) values ('YOUR-UID'); in the SQL editor.
  5. Copy the Project URL and the anon public (or publishable) key into src/data/site.json (supabaseUrl, supabaseAnonKey). Never the service_role / secret key.
  6. Run python tools/build.py, then commit and push.

The full walkthrough is in SUPABASE-SETUP.md. The print-file tool below works without a database.
